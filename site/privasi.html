Kebijakan Privasi

Terakhir diperbarui: 1 Oktober 2026

Ringkasan

Halaman ini menjelaskan informasi apa yang dikumpulkan oleh situs mihan.web.id dan oleh aplikasi pribadi "VPS Backup", serta bagaimana informasi tersebut digunakan.

Situs mihan.web.id

Situs ini adalah company profile statis. Situs ini tidak memiliki akun pengguna, tidak memiliki backend formulir, dan tidak menyimpan data yang Anda ketik di server kami.

  • Formulir kontak. Tombol "Kirim Pesan" hanya membuka aplikasi email di perangkat Anda dengan isi pesan yang sudah terisi. Kami hanya menerima informasi yang Anda kirim sendiri lewat email, dan informasi itu hanya dipakai untuk membalas pertanyaan Anda.
  • Log server. Seperti umumnya server web, permintaan ke situs ini dapat tercatat di log teknis (misalnya alamat IP, waktu akses, halaman yang diminta, dan jenis browser) untuk keperluan keamanan dan pemeliharaan. Log ini tidak dijual atau dibagikan.
  • Layanan pihak ketiga. Situs ini memuat huruf dari Google Fonts, dan halaman Kontak menampilkan peta Google Maps. Saat halaman tersebut dibuka, browser Anda terhubung langsung ke layanan Google, yang tunduk pada kebijakan privasi Google.
  • Situs ini tidak memakai cookie pelacak, analitik, atau iklan.

Aplikasi VPS Backup (Google Drive)

"VPS Backup" adalah aplikasi pribadi milik pengelola Mihan. Aplikasi ini hanya digunakan untuk mencadangkan data milik pengelola sendiri dari server (VPS) pengelola ke akun Google Drive milik pengelola sendiri. Aplikasi ini tidak ditawarkan kepada publik.

  • Izin yang diminta. Aplikasi hanya memakai cakupan https://www.googleapis.com/auth/drive.file, sehingga hanya dapat mengakses file yang dibuat oleh aplikasi itu sendiri. Aplikasi tidak dapat membaca file lain di Google Drive.
  • Penggunaan data. Akses ke Google Drive dipakai semata-mata untuk mengunggah, mencantumkan, mengunduh, dan menghapus file backup yang dibuat oleh aplikasi.
  • Enkripsi. File backup dienkripsi di server sebelum diunggah ke Google Drive.
  • Tidak ada data pengguna lain. Aplikasi tidak mengakses, mengumpulkan, menjual, atau membagikan data pengguna lain.
  • Tidak dibagikan ke pihak ketiga. Data yang diperoleh dari Google API tidak dibagikan atau dipindahkan ke pihak ketiga.
  • Tidak untuk iklan atau AI. Data dari Google tidak digunakan untuk iklan dan tidak digunakan untuk melatih model kecerdasan buatan (AI/ML).
  • Mencabut akses. Akses aplikasi dapat dicabut kapan saja melalui https://myaccount.google.com/permissions.
